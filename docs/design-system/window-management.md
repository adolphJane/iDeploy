# 窗口管理

当前 `WindowGroup("iDeploy", id: "main")` 默认 1260×800pt、最小 1000×670pt；独立 `Settings` scene 最小 740×600pt。AppKit 菜单栏图标可重新打开主窗口。全局导航状态由 App 层 `AppModel` 持有，多个主窗口可能联动；目前不把多窗口独立导航写成已支持能力。

现有对象列表宽 240–330pt，不能拖动；`PageContainer` 的详情可滚动。多个表单 Sheet 使用固定 620–650pt 宽及随内容而定的固定高度。新视图应先与这些实际尺寸对齐，再在最小窗口、全屏和较大文字下检查内容是否被裁剪。改变最小尺寸、拆分栏或弹窗尺寸属于页面改造，须保持现有保存/取消和业务目标。

窗口恢复不得自动重放发布、回滚、删除或秘密输入。设置仍由现有主导航入口与系统 Settings scene 提供；避免新增不一致的设置副本。
