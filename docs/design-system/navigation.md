# 导航与命令

当前全局侧栏包括总览、部署、服务器、项目、镜像仓库、数据库和设置，固定宽 226pt。选中行使用半透明亮绿底与右侧 3pt 标记；对象列表使用浅绿选中底与同类标记。单击对象进入详情，空选择显示空态。新增入口位于对象列表标题；对象操作位于详情上方。

当前顶部 92pt 是自绘标题/全局刷新区，并未使用 SwiftUI `.toolbar`。菜单 `操作` 已提供 ⌘R 刷新、⌘1–4 切换总览/部署/服务器/项目。表单通常以 Return 保存、Escape 取消；其他命令不要假设已有快捷键。新增命令应与实际页面操作同步，避免快捷键与文本编辑冲突。

当前列表多为自绘 `Button`，没有统一右键菜单、双击动作和可拖动分栏。后续若补充右键菜单，必须作用于右键所指对象，不得误用之前的选中项；若引入键盘方向键选择或 `NavigationSplitView`，应在页面层验证而非仅写入规范。
