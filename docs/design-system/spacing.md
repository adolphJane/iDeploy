# 间距、形状与层级

`AppSpacing` 采用 4 / 8 / 12 / 16 / 20 / 24 / 30 / 40pt 的当前常用尺度。优先使用语义用途；既有页面出现的 5、10、11、13、14、17、18pt 是已实现控件的局部尺寸，不应扩散为新的通用尺度。

| 场景 | 当前基准 |
| --- | --- |
| 主详情内边距 | `PageContainer` 30pt，内容最大宽 1080pt |
| 内容章节间 | 20pt |
| 列表栏标题内边距 | 14pt；列表行之间约 5pt |
| 列表行 | 最小高 56pt，左右 12pt；对象图标 30×30pt |
| 表单分组 | 内边距 16pt，字段间约 14–16pt |
| 卡片/GroupBox | 14pt 圆角；GroupBox 内边距 18pt |
| 主按钮 | 高 34pt、圆角 9pt |
| 次按钮 | 高 32pt、圆角 8pt |
| 选中行 | 10pt 圆角、3×20pt 亮绿标记 |

`deployCard()` 的边线为 1pt，阴影颜色 `DeployStyle.cardShadow`、模糊 22pt、下偏移 9pt。阴影只用于现有卡片层级；列表和表格不要额外堆叠。`AppRadius`、`AppShadows` 是对现有视觉的复用入口，不应让原生控件强制套同一圆角。
