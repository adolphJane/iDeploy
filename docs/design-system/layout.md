# 布局规范：以现有工作区为准

主窗口是 `ContentView` 的手工三段结构：**226pt 深绿全局侧栏 → 页面对象列表 → 详情内容**。顶部为 92pt 工作区标题/刷新区。项目、部署、服务器、仓库、数据库页面目前采用约 240–330pt 的对象列表，详情通过 `PageContainer` 滚动，最大内容宽 1080pt、内边距 30pt。设置页有独立分类侧栏。

默认主窗口为 1260×800pt，最小 1000×670pt；当前页面列表栏不能拖动调整。这是现有交互事实。新增页面应与这一壳层对齐，避免单独切成不同导航模型；若将来改为 `NavigationSplitView`，应作为独立页面迁移并验证选中、菜单和小窗口行为。

- **对象列表/详情：** 左列为名称、关键副信息、选中标记和新增入口；右列为对象标题、状态、操作、概览及后续分组。
- **总览：** 使用 `PageContainer`、三列概览块、任务和环境检查，保持当前卡片尺寸及轻量装饰。
- **表单：** Sheet 内标题、可滚动表单内容和底部保存/取消；沿用实际验证与默认值。
- **设置：** 当前同时可由主导航和独立 `Settings` scene 进入；新设计不再增加第三种入口。
- **空态：** 用浅绿图标底、标题和简短下一步说明，不加入大型插画。

在最小窗口、全屏和较长字段下必须检查主要信息与操作可达；已存在固定 sheet 宽高等限制，见[窗口管理](window-management.md)。
