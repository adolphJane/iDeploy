# 辅助功能与当前限制

当前自绘视觉以固定浅色值和 10–12pt 小字号为主，多个页面或表单强制浅色；完整 Dark Mode、高对比度、放大文字与 VoiceOver 流程**尚未验证**。统一规范不能把预览里的外观视为业务页已经达标。

- 纯图标按钮提供可朗读名称与 Help；状态徽标保留文字，不只依赖红/绿。
- 自绘选中行应声明选中状态；键盘焦点与鼠标 Hover 必须区分，不能用背景覆盖系统焦点轮廓。
- 表单字段保留标签、必填及错误说明；保存/取消与 Return/Escape 逻辑一致。秘密值只呈现配置状态，不在日志、预览或辅助文本中泄露。
- 长路径、镜像引用和错误详情允许选取复制；较大文字时应换行或滚动，不能无提示截断。
- 后续适配 Dark/高对比度需成套迁移 `DeployStyle` 的画布、内容面、正文、次文字、边线与品牌色，再逐页运行时检查对比度，正文目标至少 4.5:1。
- 验收组合：最小/默认/宽窗口 × Light/Dark × 普通/提高对比度 × 正常/放大文字；另外检查 Tab、VoiceOver、鼠标和减少动态效果。未实测项目应在报告中明确标记。
