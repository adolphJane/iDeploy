# 交互规范

## 已有行为

- **鼠标：** 单击侧栏/对象行选中；列表新增按钮有提示；详情操作通过 Button、Menu 和 Sheet 完成。当前自绘列表没有统一 Hover 动画或右键菜单。
- **键盘：** 应用菜单提供 ⌘R、⌘1–4；若表单声明 `.defaultAction` / `.cancelAction`，Return / Escape 对应保存与取消。原生控件继续保留系统 Tab 与焦点行为。
- **反馈：** 主窗口显示后台连接进度和全局错误 Alert；页面使用状态徽标、空态、任务进度、确认对话框。删除与回滚的真实业务确认保持原样。

## 新视图的统一规则

1. 主要操作在详情首屏清晰可见；次要操作用原生按钮或 Menu。不要把同一动作无意义地重复在多个位置。
2. 自绘行的 Hover 可用很浅的 `greenSoft` 表示，但选中必须有明确文字/背景/标记；键盘焦点不可被 Hover 背景覆盖。
3. 右键、双击或拖放只在明确任务语义存在时加入，且必须与同一对象的主操作一致。
4. 运行状态、错误和成功使用文字说明；长时间任务展示进度，不用一次性成功提示掩盖远端 Job 的真实状态。
5. 危险操作确认需指出目标和影响。回滚、发布、重试调用保持现有参数与任务语义，不因视觉规范改变。
6. 动效短而克制，尊重系统减少动态效果。
