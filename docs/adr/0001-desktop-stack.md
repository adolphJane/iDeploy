# ADR 0001：桌面端技术栈与运行边界

- 状态：已采纳
- 日期：2026-09-03

## 背景

iDeploy 是面向单用户的 macOS 本地应用，需要管理本地/Git 项目、调用 Docker 构建与发布镜像，并通过 SSH 运维远程服务器上的 Docker 项目。应用数据和凭据索引保存在本机，不建设独立服务端。

## 决策

- 桌面外壳采用 Wails v3，后端使用 Go，前端使用 Vue 3 与 TypeScript。
- 最低支持 macOS 13，首要验证 Apple Silicon；后续发布同时提供 arm64 与 amd64 构建。
- 本地结构化数据使用 SQLite，并启用 WAL、外键与 busy timeout。
- 长时间操作统一进入持久化任务队列；任务状态、进度、日志和操作事件可在应用重启后恢复或追溯。
- Docker、Git、SSH 等外部命令只通过参数数组调用，不拼接 shell 命令。
- 可执行文件解析先检查应用进程的 `PATH`。在 macOS 上未找到时，通过 `/bin/zsh -lic` 加载用户的 `.zprofile` 和 `.zshrc` 后再次解析，以兼容从 Finder 启动时环境变量不完整的情况。
- 敏感凭据后续写入 macOS Keychain；SQLite 只保存引用与非敏感元数据。

## 取舍与风险

Wails v3 当前仍为 beta。它能提供体积较小的原生 macOS 应用、直接的 Go 能力和 Vue 开发体验，但升级可能包含破坏性变更。因此锁定 CLI 与 Go 模块版本，CI 必须执行前端构建、Go 测试和 macOS 应用打包；若 beta 稳定性影响交付，则评估回退 Wails v2，而不改变领域层和任务模型。

通过登录式交互 zsh 读取用户配置可能产生插件输出或配置错误。解析器使用唯一标记提取命令路径、忽略其他输出，并仅接受绝对且可执行的文件；此过程只在普通 `PATH` 查找失败时触发。

## 结果

领域逻辑保持在 Go 包中，Vue 仅负责展示和发起操作。后续服务器、项目、Registry 与部署模块都复用同一任务队列、事件记录、路径解析和凭据边界。
